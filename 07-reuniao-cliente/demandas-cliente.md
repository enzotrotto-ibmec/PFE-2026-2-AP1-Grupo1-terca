# 📦 **Demandas do cliente PKZLAB & One to One**

## 📋 Requerimentos

### Sistema centralizado

- Concentrar todas as informações (agendamentos, relatórios, avaliações, arquivos) dentro de um único sistema, em vez de espalhadas em Drive, Excel etc.

- Controlar os retestes físicos, utilizando um painel ou sistema de alerta que mostre facilmente quais alunos estão com os testes físicos vencidos ou atrasados, para que o treino do dia seja substituído pela reavaliação.

- Parametrização de testes, em que o sistema deve avaliar e comparar o atleta estritamente dentro de sua própria categoria de idade e modalidade praticada.

### Relatórios e dashboards

- Gerar relatórios/dashboards automaticamente a partir dos dados inseridos do aluno, sem precisar escrever um prompt manual toda vez para uma IA.

- Possibilitar o envio de informações e relatórios diretamente para os pais ou responsáveis pelos atletas de forma mais eficiente.

- Facilitar as entregas, tornando os relatórios mais visuais e "palpáveis", já que hoje são muito extensos e cheios de números, difíceis de interpretar por pais sem conhecimento técnico.

- Duplo relatório, funcionando da seguinte forma: assim como o professor preenche o relatório após a aula, o sistema deve permitir que o aluno avalie o treino do professor, para que a coordenação possa recolher feedbacks.

- Facilitar a navegação/visualização dos relatórios (o processo atual de abrir um relatório de teste foi descrito como pouco intuitivo, com muitos cliques).

- Possibilidade de anexar/gerar automaticamente relatórios de tipos diferentes de teste (ex.: teste de fisioterapeuta), que hoje só podem ser anexados como arquivo externo, não gerados pelo próprio sistema.

### Gráficos de evolução

- Criar gráficos evolutivos (como os de exames de sangue) mostrando a progressão do aluno ao longo do tempo em cada métrica avaliada, para que o responsável veja a evolução de forma visual e rápida.

### Agendamento

- Histórico de treinos integrado à agenda, no qual o sistema mostra automaticamente para o professor o relatório e as observações do treino anterior do aluno no momento em que ele acessa o agendamento do dia, sem precisar pesquisar manualmente.

- Adicionar na agenda geral uma aba/indicação rápida do próximo foco de treino (ex.: "membros inferiores"), linkada ao relatório do último treino, sem precisar abrir o relatório separadamente.

- Aperfeiçoar o sistema para que os alunos possam marcar e desmarcar treinos sozinhos com base nas vagas disponíveis, sem precisarem enviar mensagens para a recepção.

- Exibir a quantidade de créditos semanais de cada aluno (ex.: 5) que são utilizados para marcar treinos ou testes. Os créditos não se acumulam, sendo restaurados para o valor cheio no início de cada semana.

### Comunicação e notificações

- Enviar notificações/lembretes via WhatsApp para o aluno sobre agendamentos (confirmação do agendamento e lembrete próximo do horário).

### Financeiro/cobrança

- Criar uma área de cobrança para os alunos, informando mensalidade vencida, data de vencimento e forma de pagamento.

- Disponibilizar uma área para que o aluno visualize se os pagamentos estão em dia.

- Permitir que o aluno altere a forma de pagamento pelo próprio sistema (ex.: trocar de débito para cartão de crédito).

### Website

- Portfólio com fotos e vídeos dos treinos, tanto do PKZ quanto do One to One.

- Possibilidade de cadastro do aluno pelo próprio site, gerando login e senha.

- Algum link/integração entre o site e o aplicativo, facilitando o aluno baixar o app e se inscrever.

- Opção de contato via WhatsApp pelo site.

### Análise de desempenho / Scout

- Facilitar/automatizar o processo de análise de desempenho e scout de jogos, que hoje é feito manualmente assistindo vídeos inteiros e marcando passes, finalizações etc.

- Resolver especificamente o problema de ter que reassistir o mesmo jogo várias vezes quando precisam analisar jogadores diferentes que jogaram a mesma partida.

### Identidade visual

- Deixar as marcas (PKZ e One to One) com uma apresentação mais coesa, visual e funcional, trazendo 'mais glamour', pois hoje falta um acabamento mais profissional no app atual.
